# Yosemite Valley

Created by Steve Sheets on November 2, 2026.

Atlas ID: `magesteve.yosemitevalley`.

[Open the example page](https://zodiacinnovations.com/aetheratlas/examples/yosemitevalley/) · [Atlas descriptor](https://zodiacinnovations.com/aetheratlas/examples/yosemitevalley/yosemitevalley.aetheratlas)

All eight photographs and the valley map use external HTTPS Wikimedia image URLs. This folder intentionally contains no images or movies. Glacier Point is a wide panorama, not a full 360° sphere; all other locations are ordinary images. Map pins remain unassigned, matching the existing inspection examples.

The Yosemite Lodge stop shows Half Dome at sunset from near the lodge, rather than its buildings. The historical Firefall stop shows the former man-made Glacier Point event, not the natural Horsetail Fall lighting effect. The map is an older NPS brochure map; it does not establish current roads, services, or access.
