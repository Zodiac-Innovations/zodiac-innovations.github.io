# National Mall, Washington, DC

Created by Steve Sheets on November 1, 2026.

Atlas ID: `magesteve.dcmall`. Lowercase IDs are encouraged for consistency, but are not mandatory. IDs remain case-sensitive; no lowercase validation rule is introduced.

[`dcmall.aetheratlas`](dcmall.aetheratlas) follows the current Oz example's evolving format, including `name`, `version`, `url`, and `details.initiallocation`. All twelve destination images and the map are hosted alongside this descriptor on the Zodiac Innovations website. Original source and rights records are retained in sources.json.

## Inspect the twelve images

These are twelve images, not twelve distinct monuments. The first is a genuine 6720 × 3360 equirectangular image captured with a Ricoh THETA Z1. The remaining eleven are ordinary photographs and must not be stretched onto a full sphere. Views concentrate on the Lincoln, Washington, and Jefferson memorial sites and the Mall.

## Map

[National Mall brochure map and public-domain record](https://commons.wikimedia.org/wiki/File%3ANPS_national-mall-map.jpg) · [Original map image](national-mall-map.jpg).

The map is the NPS brochure map, with restoration/cleanup credited to National Park Maps. Its source record identifies it as public domain in the United States. Map pins are currently unassigned: this is an image-inspection sample, and pin coordinates should be placed after reviewing the map and selected views. Locations remain available in descriptor order.

## Rights and provenance

Eleven photo records identify official NPS works as public domain in the United States; the Jefferson statue photo was dedicated to the public domain by its photographer, Sox524. No CC BY, CC BY-SA, stock-photo license, or attribution license is used for these images. Public-domain determinations and source URLs are recorded in [sources.json](sources.json), separately from the evolving atlas schema. Credits document provenance and do not imply NPS endorsement. Public-domain status is jurisdiction-specific; these records do not assert worldwide status for federal works.

## Availability and checks

Original Wikimedia image links were resolved through their file pages on November 1, 2026. External hosting is outside this repository's control. The map is a historical brochure image, not a guarantee of current visitor access or facilities.

This descriptor uses the current example schema; the CLI README still documents an earlier schema, so compatibility must be rechecked after the ongoing format changes land. Local `validate` is designed for self-contained folders and rejects external URLs. Remote validation requires the descriptor itself to be publicly accessible without authentication. The examples repository was private when inspected, so its raw descriptor URL is not currently suitable for unauthenticated `remote` use; external image URLs are public. No authentication support is added.
